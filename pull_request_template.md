## Чеклист

- [ ] Заголовок PR — в формате Conventional Commits (`feat: ...`, `fix: ...`)
- [ ] Ветка синхронизирована с актуальным `main`
- [ ] Стоят type label и release label (`major` / `minor` / `patch` / `no-release`)
- [ ] CI зелёный, хуки не обходились
- [ ] Новая логика покрыта тестами, багфикс — тестом, который воспроизводит баг
- [ ] В коде, фикстурах и логах нет секретов, токенов и реальных персональных данных
- [ ] Новые переменные окружения добавлены в `.env.example`
- [ ] Документация обновлена, если поведение изменилось

### Если PR трогает работу с внешними API

- [ ] У запросов есть таймаут и лимит размера ответа
- [ ] Кривой ответ внешнего API превращается в результат проверки, а не роняет обработку
- [ ] Нарушение контракта, ошибка запроса и внутренняя ошибка не смешиваются

### Если PR меняет API бэкенда

- [ ] Обновлена OpenAPI-спецификация
- [ ] Breaking change помечен `major`, фронт предупреждён
